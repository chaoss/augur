In mid-April [the CHAOSS Board shared an update](https://chaoss.community/public-update-on-recent-events-at-chaoss/) formally acknowledging that the Augur project has been moved outside of the CHAOSS organization and is no longer part of CHAOSS.

To continue the valuable metrics collection work within CHAOSS, the CollectOSS (pronounced “Collect Us”) project has been created with a new name and a transparent, community-first governance structure. The repository for this project is [https://github.com/chaoss/CollectOSS/](https://github.com/chaoss/CollectOSS/)

This project is based on a fork of the Augur code and the initial 1.0.0 release is intended to be as drop-in of a migration as possible. Written wikis, [migration guides](https://github.com/chaoss/CollectOSS/wiki/Migration-Guide), [FAQ](https://github.com/chaoss/CollectOSS/wiki/Migration-FAQ)’s, and community slack support (in the \#wg-collectoss-8knot channel) are also available to help aid in the transition to this new project. CollectOSS project maintainers are also happy to assist with migrating your instances and contributions to the new project, as well as answer any other questions you have.

We would love to invite you to become part of the community (as a user, contributor, or even a future maintainer), you can join the CHAOSS slack and get involved by visiting [https://chaoss.community/kb-getting-started/](https://chaoss.community/kb-getting-started/)

We also have an updated [CONTRIBUTING.md](https://github.com/chaoss/CollectOSS/blob/main/CONTRIBUTING.md) and a new documentation website at [https://docs.collectoss.org](https://docs.collectoss.org) to help you make either your first or next contribution. We are always looking for contributions to improve our docs, automate testing, and keep CollectOSS running as smoothly and efficiently as possible.

I look forward to welcoming you to the CollectOSS community and constructively working towards our mission to help everyone in open source understand the health of their communities\!
